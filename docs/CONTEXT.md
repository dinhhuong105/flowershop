# CONTEXT — Hoa Tươi Demo (dán đầu chat mới thay đoạn dặn dò dài)
Stack: Next.js 15 (App Router) + TypeScript + Tailwind v4; PostgreSQL 16 + Prisma 6.19.3; Docker + Caddy (VPS Ngày 10); VietQR tự dựng + Telegram báo đơn.
Repo: github.com/dinhhuong105/flowershop (public), nhánh main. Kiểm chứng bằng Node 22 (~/tools/node22/bin/node). Docker KHÔNG chạy container được trên máy Muse (host không cấp cgroup controller) — kiểm chứng native.
Quy tắc đứng: không loading.tsx, không bọc nội dung chính trong Suspense; trang noindex miễn điểm SEO Lighthouse; chỉ học cấu trúc edengift.com, không chép câu chữ/ảnh/giá; mục chưa chạy ghi CHƯA KIỂM TRA; commit cuối ngày; Dockerfile/docker-compose.yml không đổi.
Lệnh: npm run typecheck | npm run lint | npm test | npm run build (Node 22, 0 lỗi). Máy chủ: node --env-file=.env .next/standalone/server.js (cổng 3000); sau mỗi build copy .next/static + public vào .next/standalone/; postbuild xóa .next/standalone/.env.
Cấu trúc: src/app (trang + api), src/lib (+ admin/), src/components, src/config, prisma (migrations + seed), scripts/, docs/reports/.
Biến môi trường: DATABASE_URL, SITE_URL, SHOP_NAME, HOTLINE, ZALO_PHONE, SHOP_ADDRESS, OPEN_HOURS; BANK_* (VietQR); TELEGRAM_* (báo đơn); ADMIN_USERNAME (mặc định admin) + ADMIN_PASSWORD_HASH (scrypt$<saltHex>$<hashHex>); UPLOAD_DIR (mặc định ./data/uploads); ADMIN_COOKIE_SECURE=false chỉ để thử HTTP.
URL cố định TIẾNG ANH (Henry 23/11): /cart, /checkout, /order/[mã], /search, /login, /admin, /admin/products... URL cũ tiếng Việt redirect 301. Slug danh mục/sản phẩm (lấy từ DB) giữ tiếng Việt.
Quyết định đã chốt: giỏ lưu DB (cookie cart_token, HttpOnly); COD + chuyển khoản (thiếu BANK_* thì ẩn); nội dung chuyển khoản "DH <mã đơn>"; khung giờ chỉ chọn khi start >= t + 120 phút; giao nhanh 2h "Trong 2 giờ kể từ khi shop xác nhận", trong ngày "Trước 18:00"; trạng thái đơn NEW→CONFIRMED→DELIVERING→COMPLETED/CANCELLED (PREPARING còn trong enum nhưng không nằm trong luồng Ngày 8); phí ship theo khu vực (mẫu 25k/35k/50k/70k); tên ngân hàng hiển thị lấy từ BIN (bảng trong src/lib/bank.ts).
Quản trị: phiên 12 giờ (cookie admin_session, HttpOnly, SameSite=Strict); giới hạn 5 lần sai/15 phút theo IP, 20 lần toàn hệ thống → 429; IP lấy từ X-Forwarded-For — chỉ tin TRUSTED_PROXY_HOPS phần tử cuối (mặc định 1); ảnh tải lên JPEG/PNG/WebP ≤5 MB, ≤6/SP, tên do máy chủ sinh, lưu UPLOAD_DIR (trên Vercel không bền — xử lý Ngày 10 VPS).
Tìm kiếm: không phân biệt dấu (vi_unaccent), 8/trang; Xem nhanh <dialog> lười tải; toast "Đã thêm vào giỏ" hiện 3 giây sau khi cửa sổ đóng; First Load JS của / ≤135 kB.
